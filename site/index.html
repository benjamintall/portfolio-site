This site is a project

I built and deployed this page on Azure as a hands-on way to learn the platform. The infrastructure is written as code, and every change goes live through a pipeline.

  • Hosted on Azure Static Web Apps, Free plan.
  • Infrastructure defined in a Bicep template and deployed with the Azure CLI.
  • GitHub Actions deploys on every push to main, with a temporary preview environment for each pull request.
  • Resources sit in a tagged resource group, with a budget alert on the subscription.

Planned next: a custom domain with Azure DNS, monitoring and an alert, and a contact form backed by Azure Functions and Key Vault.
